# Guide utilisateur NOLI — Espace Assureur

Ce guide s'adresse aux **compagnies d'assurance** partenaires de NOLI. Il explique comment vous connecter à votre espace, suivre votre activité, gérer vos offres et garanties, traiter les devis reçus, suivre vos contrats et clients, et traiter les sinistres déclarés.

Il est rédigé simplement : suivez les étapes numérotées.

---

## Avant de commencer (prérequis)

- **Adresse du site** : https://noli.ci
- **Un compte assureur activé** : votre compte est créé lors de l'inscription (profil « Assureur »), mais il doit être **activé par un administrateur NOLI** avant sa première utilisation. Tant qu'il n'est pas activé, votre espace peut afficher un message indiquant que le compte assureur n'est pas encore configuré.
- **Identifiants** : l'email et le mot de passe choisis lors de votre inscription.

> **Important** : à la création d'un compte assureur, un message vous rappelle qu'« un administrateur doit activer votre espace assureur avant sa première utilisation ». Si votre espace semble vide ou verrouillé, contactez l'administrateur NOLI pour l'activation et le rattachement de votre compte à votre compagnie.

---

## 1. Se connecter

1. Rendez-vous sur https://noli.ci et cliquez sur **Connexion**.
2. Saisissez votre **email** et votre **mot de passe**, puis cliquez sur **Se connecter**.
3. Vous êtes redirigé vers votre **Tableau de bord assureur**.
4. Pour vous déconnecter, ouvrez le menu de votre profil (en haut à droite) et choisissez **Déconnexion**.

Le menu de gauche donne accès à toutes vos rubriques : **Tableau de bord, Clients, Contrats, Sinistres, Offres, Devis Reçus, Rappels, Analytics, Mes Garanties, Paramètres**.

---

## 2. Consulter le tableau de bord

1. Cliquez sur **Tableau de bord** dans le menu de gauche.
2. Vous y trouvez vos **indicateurs clés** : nombre de devis (total, en attente, approuvés, rejetés), taux d'approbation, nombre de garanties configurées, et le rappel « devis → contrats ».
3. Un tableau **Devis récents** affiche les dernières demandes reçues avec leur **statut** (En attente, Approuvé, Rejeté, Brouillon).

> Si le message « Compte assureur non configuré » apparaît, votre compte n'est pas encore activé/rattaché : contactez l'administrateur NOLI.

---

## 3. Consulter les Analytics

1. Cliquez sur **Analytics** dans le menu de gauche.
2. Vous visualisez :
   - le **taux d'approbation** de vos devis,
   - la **répartition des devis par statut** (En attente, Approuvé, Rejeté, Brouillon),
   - le nombre de **garanties configurées**,
   - la liste des **derniers devis reçus**.
3. Ces indicateurs vous aident à piloter votre activité et à ajuster vos offres.

---

## 4. Gérer ses offres

1. Cliquez sur **Offres** dans le menu de gauche.
2. Pour **créer une offre**, cliquez sur **Créer une offre**, remplissez les informations (nom, type de contrat, garanties associées, statut actif/inactif…) puis validez. Un message « Offre créée » confirme l'opération.
3. Pour **modifier** une offre existante, cliquez sur **Modifier** sur la carte de l'offre, ajustez les champs et enregistrez.
4. Pour **supprimer** une offre, cliquez sur **Supprimer** et confirmez.
5. Chaque offre indique son **statut** (Actif / Inactif) et les **garanties** qui la composent.

---

## 5. Gérer ses garanties

1. Cliquez sur **Mes Garanties** dans le menu de gauche.
2. Pour **créer une garantie**, lancez l'assistant et renseignez :
   - **Étape 1** : le **nom** de la garantie (obligatoire) et, le cas échéant, la **garantie requise** (code d'une garantie nécessaire pour activer celle-ci) et le **capital de garantie**,
   - **Étape 2** : le **mode de calcul** de la prime (obligatoire) — par exemple montant fixe, calcul en pourcentage d'une variable, ou garantie incluse (prime = 0 FCFA),
   - selon le mode choisi : la **prime**, le **prix en pack**, la **franchise** (aucune, pourcentage ou montant fixe), etc.
3. Validez : un message « Garantie créée » (ou « Garantie mise à jour ») confirme l'enregistrement.
4. Vous pouvez **modifier** ou **supprimer** une garantie existante depuis la liste.

> Les garanties que vous configurez alimentent vos offres et donc les devis proposés aux clients.

---

## 6. Traiter les devis reçus

Lorsqu'un client demande un devis sur l'une de vos offres, celui-ci apparaît dans **Devis Reçus**.

1. Cliquez sur **Devis Reçus** dans le menu de gauche.
2. Filtrez la liste par statut : **Tous, Brouillons, En attente, Approuvés, Refusés**.
3. Pour chaque devis en attente, deux actions principales :
   - **Approuver** : le devis passe au statut **Approuvé**. **Un contrat est alors créé** à partir de ce devis.
   - **Rejeter** : le devis passe au statut **Refusé**.
4. Vous pouvez également remettre un devis **En attente** si vous devez le réexaminer.
5. Un message de confirmation s'affiche après chaque changement de statut.

> **Le lien devis → contrat** : approuver un devis déclenche la création du contrat correspondant. Vous le retrouverez ensuite dans **Contrats**.

---

## 7. Consulter ses contrats

1. Cliquez sur **Contrats** dans le menu de gauche.
2. La liste présente les **contrats souscrits via vos offres**, avec le **client**, l'**offre**, la **référence** et le **statut** (par exemple **Actif**). Un indicateur affiche le nombre de **contrats actifs**.
3. Utilisez la **barre de recherche** pour retrouver un contrat par client, offre ou référence.

> Rappel : les contrats apparaissent ici **après l'approbation et la finalisation d'un devis** par un client.

---

## 8. Consulter son portefeuille clients

1. Cliquez sur **Clients** dans le menu de gauche.
2. Vous visualisez la liste de vos **clients** et, pour chacun, le nombre de **contrats** rattachés.
3. Utilisez la recherche pour retrouver un client précis.

---

## 9. Gérer les demandes de rappel

1. Cliquez sur **Rappels** dans le menu de gauche.
2. Vous y retrouvez les clients ayant demandé à **être rappelés** au sujet de vos offres, avec leur numéro et le créneau souhaité.
3. Filtrez par **Nouvelles** (non traitées) ou consultez l'ensemble, puis marquez les demandes comme traitées après avoir contacté le client.

---

## 10. Traiter les sinistres déclarés

Les sinistres déclarés par les clients sur leurs contrats actifs remontent dans l'onglet **Sinistres**.

1. Cliquez sur **Sinistres** dans le menu de gauche.
2. Des compteurs vous indiquent les sinistres **Reçus**, **En cours d'examen** et **Traités**.
3. Utilisez la **recherche** pour retrouver un sinistre par référence, client, contrat ou type.
4. Pour chaque sinistre, ouvrez la liste **Faire évoluer** et choisissez le nouveau **statut** :
   - **Reçu** (déclaration initiale),
   - **En cours d'examen**,
   - **Approuvé**,
   - **Rejeté**,
   - **Clôturé**.
5. Un message « Sinistre mis à jour » confirme le changement, et le client est tenu informé de l'évolution.

---

## 11. Paramètres de l'entreprise

1. Cliquez sur **Paramètres** dans le menu de gauche.
2. Vous pouvez mettre à jour les informations de votre **entreprise** : nom, email et téléphone de contact.
3. Enregistrez : un message « Entreprise mise à jour » confirme la sauvegarde.

---

## FAQ / Dépannage

**Mon espace affiche « Compte assureur non configuré » ou semble vide.**
Votre compte n'est pas encore **activé** par un administrateur, ou n'est pas rattaché à votre compagnie. Contactez l'administrateur NOLI pour l'activation et le rattachement.

**Je viens de m'inscrire, que se passe-t-il ?**
Un message vous rappelle qu'un administrateur doit activer votre espace avant sa première utilisation. Une fois l'activation faite, vos rubriques deviennent pleinement fonctionnelles.

**J'ai approuvé un devis : où est le contrat ?**
Approuver un devis crée automatiquement le contrat. Retrouvez-le dans l'onglet **Contrats** (après finalisation côté client).

**Une garantie ne s'enregistre pas.**
Vérifiez que le **nom** (étape 1) et le **mode de calcul** (étape 2) sont bien renseignés — ils sont obligatoires. Vérifiez aussi que votre compte assureur est bien configuré.

**Comment un client peut-il me contacter avant de souscrire ?**
Via le bouton **Être rappelé** sur vos offres. Ces demandes remontent dans l'onglet **Rappels**.

**Je ne vois pas certains devis.**
Vérifiez le **filtre de statut** actif dans « Devis Reçus » et repassez-le sur **Tous**.
